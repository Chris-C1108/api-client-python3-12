# Product Overview

Gophish Python API Client is a Python library that provides programmatic access to the Gophish phishing framework. Gophish is an open-source phishing toolkit designed for businesses and penetration testers to conduct authorized phishing simulations.

## Purpose
- Enables Python developers to interact with Gophish's REST API
- Provides a clean, object-oriented interface for managing phishing campaigns
- Supports all core Gophish functionality: campaigns, groups, templates, pages, SMTP settings, and webhooks

## Key Features
- Campaign management (create, launch, monitor, complete)
- Target group management
- Email template and landing page creation
- SMTP configuration
- Webhook integration for real-time notifications
- IMAP integration for email reporting
- Comprehensive result tracking and analytics

## Target Users
- Security professionals conducting authorized phishing assessments
- Developers building security awareness training platforms
- Penetration testers automating phishing campaign workflows
